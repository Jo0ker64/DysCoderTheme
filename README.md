## Recommandation de police

Ce thème est optimisé pour les polices adaptées comme `OpenDyslexic` ou `Lexend`.

### Installer une police :
- Téléchargez et installez [OpenDyslexic](https://opendyslexic.org/) ou [Lexend](https://fonts.google.com/specimen/Lexend).
- Ajoutez ceci dans vos paramètres VS Code (`settings.json`) ou remplacez la police existante par : 
```json
  "editor.fontFamily": "'OpenDyslexic', 'Lexend', Consolas, 'Courier New', monospace"
```
