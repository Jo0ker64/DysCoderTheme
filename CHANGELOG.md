## [1.0.0] - 2026-09-30

### Added

- First public release of DysCoder Universal, a dark Visual Studio Code theme built around a stable color for each code role.
- A calm anthracite interface palette with high-visibility comments, indentation guides, and active-code indicators.
- Semantic highlighting and TextMate rules for common code elements.
- Targeted syntax rules for HTML, CSS, JavaScript/TypeScript, Python, PHP, SQL, JSON, and Java.
- DysCoder Reading Profile, an optional settings preset for more spacious code and project navigation.
- OpenDyslexic installation guidance and optional reading settings.
- Marketplace icon, dark-theme preview, French README, and English README.
