1. Contraste entre le texte et l’arrière-plan :

Le rapport de contraste mesure la différence de luminosité entre deux couleurs, en tenant compte de leur perception par l'œil humain. Pour garantir que le texte soit lisible sur un arrière-plan, le rapport recommandé est de 7:1 pour les contenus essentiels. Ce seuil est défini par les normes d'accessibilité (WCAG - Web Content Accessibility Guidelines).

    Pourquoi 7:1 ?
        Ce rapport assure que les personnes ayant une déficience visuelle ou une vision altérée (comme le daltonisme ou la presbytie) peuvent lire sans difficulté.
        Cela améliore également le confort visuel général, en particulier pour les longues sessions de lecture ou de codage.

    Exemple de bons contrastes :
        Texte blanc (#FFFFFF) sur un arrière-plan noir (#000000) → Rapport de contraste : 21:1 (très bon).
        Texte jaune vif (#FBFF00) sur un fond noir (#000000) → Rapport : 19.56:1 (excellent).
        Texte gris clair (#D4D4D4) sur un fond noir (#000000) → Rapport : 10.51:1 (bon).

    Exemple de mauvais contrastes :
        Texte gris moyen (#AAAAAA) sur un fond gris foncé (#333333) → Rapport : 3.99:1 (faible).

2. Visibilité des éléments clés :

Certains éléments nécessitent des couleurs très distinctives pour attirer l'attention et signaler leur importance :

    Erreurs : Rouge vif (#FF0000) pour indiquer les erreurs.
        Contraste avec l’arrière-plan : L’erreur doit "sauter aux yeux" pour ne pas être manquée.
        Exemple : Rouge vif sur un fond noir ou sombre → Rapport > 7:1.

    Avertissements : Jaune vif (#FFFF00 ou proche) pour des alertes ou avertissements.
        Il doit rester visible mais moins "agressif" qu’une erreur.

    Informations : Bleu vif (#0080FF ou similaire) pour signaler des informations ou des messages non urgents.

    Sélections : Une couleur d’arrière-plan bien contrastée (par exemple, #2B2D12 sur du texte clair ou #FFD700 sur du texte sombre) aide à repérer les sélections rapidement.

Comment tester les contrastes :

    Outils en ligne :
        Utilisez des outils comme Contrast Checker pour calculer le rapport entre deux couleurs.

    Exemple avec votre thème :
        Texte jaune vif (#FBFF00) sur un fond gris foncé (#272727) :
            Rapport de contraste : 13.96:1 (excellent).
        Texte blanc (#FFFFFF) sur un fond noir (#1D1D1D) :
            Rapport de contraste : 16.21:1 (très bon).

    Simulateur de daltonisme :
        Testez vos couleurs pour vérifier qu’elles sont lisibles par des personnes daltoniennes (exemple : rouge et vert ne doivent pas être trop proches).
